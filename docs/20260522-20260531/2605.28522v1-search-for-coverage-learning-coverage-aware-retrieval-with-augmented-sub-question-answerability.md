## 摘要
长文本检索增强生成（RAG）带来了基于覆盖排序的挑战，因为排序方法必须确保包含全面的相关片段（即事实），从而综合生成全面的输出。在这项工作中，我们提出了CoveR（代码可在https://github.com/DylanJoo/CoveR获取），一种针对覆盖感知检索场景优化的稠密检索方法。CoveR是一种双编码器，通过基于覆盖的对比和蒸馏目标进行训练，使其能够捕捉信息需求的不同方面。为了训练CoveR，我们创建了SCOPE数据集（训练数据可在https://huggingface.co/datasets/DylanJHJ/scope获取），该数据集包含来自研究性问题的9万个训练对，并带有由LLM生成的子问题可回答性判断增强的合成覆盖信号。我们的实验表明，与强稠密检索基线相比，CoveR在不牺牲相关性检索能力的情况下，将片段覆盖提高了10%。进一步的消融研究验证了我们提出的学习方法的重要性，表明CoveR在相关性和基于覆盖的排序之间实现了更优的权衡，这对于长文本RAG至关重要。

## Abstract
Long-form Retrieval-Augmented Generation (RAG) brings the challenge of coverage-based ranking, because ranking methods must ensure the inclusion of comprehensive relevant nuggets (i.e., facts), which can thereby be synthesized into a comprehensive output. In this work, we propose CoveR (Our code is available at https://github.com/DylanJoo/CoveR ) a dense retrieval method optimized for coverage-aware retrieval scenarios. CoveR is a bi-encoder trained with the coverage-based contrastive and distillation objectives, which enables CoveR to capture diverse aspects of information needs. To train CoveR, we create the SCOPE dataset, (Our training data is available at https://huggingface.co/datasets/DylanJHJ/scope ) which comprises 90K training pairs from Researchy Questions with synthetic coverage signals augmented from sub-question answerability judgments generated by LLMs. Our empirical experiments show that CoveR enhances nugget coverage by 10\% over strong dense retrieval baselines without sacrificing its relevance-based retrieval capability. Further ablation studies validate the importance of our proposed learning method, showing that CoveR achieves a superior trade-off between relevance- and coverage-based ranking, which is essential for long-form RAG.

- **核心问题**：现有检索方法主要针对**单个文档的相关性**进行优化，使用如 MS MARCO 等数据集训练，使查询与相关文档在嵌入空间聚集。但在**长文本检索增强生成（Long-form RAG）** 场景中（例如生成综合报告），用户查询常包含多个子信息需求，检索的目标是确保**检索到的文档集合能够全面覆盖所有相关信息片段（nuggets）** 而非仅仅找到最相关的单篇文档。
- **研究动机**：文档级相关性提升并不能有效转化为事实片段覆盖度的提升，因为高排名文档可能包含相似的事实。因此需要一种**覆盖感知（Coverage-aware）** 的检索方法，同时兼顾相关性和覆盖面。
- **整体含义**：本文推动了检索范式从“最佳文档”向“最佳覆盖集合”的转变，为下一代搜索引擎（如集成 LLM 的报告生成）提供了基础检索能力。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
- 设计**双编码器（Bi-encoder）** 架构，通过**覆盖对比学习（Coverage Contrastive Learning, CovCon）** 和**覆盖自蒸馏（Coverage Self-Distillation, CovDistil）** 两种目标，将覆盖信号编码到查询和文档的表示空间中。
- 利用子问题（Sub-questions）作为信息片段的代理，通过 LLM 生成子问题的可回答性判断，构建覆盖分数。

### 2.2 关键技术细节
- **双编码器结构**：
  - 查询编码：`E_q = Enc_θ("search_query: {q}")`
  - 文档编码：`E_d = Enc_θ("search_document: {d}")`
  - 相似度计算：`s(q,d) = Mean(E_q) · Mean(E_d) / (||Mean(E_q)|| · ||Mean(E_d)||)`
- **覆盖对比学习（CovCon）**：
  - 正样本：高覆盖分数（如覆盖度 > 50% ）的文档
  - 负样本：低覆盖分数（如覆盖度 ≤ 0 ）的文档
  - 损失函数：`L_CovCon = -log( exp(s(q,d+)/t) / Σ exp(s(q,d')/t) )`（与标准对比学习同形式，但正负样本按覆盖度选取）
- **覆盖自蒸馏（CovDistil）**：
  - 教师分数：聚合所有子问题与文档的相似度平均，构建教师分布 `P_sq(d|q)`
  - 学生分数：原始查询与文档的相似度分布 `P(d|q)`
  - 损失函数：`L_CovDistil = λ_CD · KLDiv(P(d|q) || P_sq(d|q))`，用于稳定训练并防止相关性坍塌
- **两阶段训练**：
  1. 相关性预微调（Pre-finetuning）：在 MS MARCO 上使用标准相关性对比学习（3 个 epoch）。
  2. 覆盖微调：在 SCOPE 数据集上使用 CovCon + CovDistil 联合训练（3 个 epoch）。
- **SCOPE 数据集构建**：
  - 基于 Researchy Questions（9 万训练查询），包含 GPT-4 分解的子问题。
  - 对每个查询，用 BM25 检索 top-100 候选文档，再用 Qwen3 重排序器筛选 top-20。
  - 使用 Llama 3.3 70B 对每个（子问题，文档）对进行 0-5 分可回答性评分（共 2400 万评分）。
  - 以阈值 4 定义可回答，计算覆盖分数 = 可回答子问题数 / 总子问题数。
  - 按覆盖度分组采样正负样本：正样本来自覆盖度 [50%,100%]，负样本来自覆盖度 ≤0。
