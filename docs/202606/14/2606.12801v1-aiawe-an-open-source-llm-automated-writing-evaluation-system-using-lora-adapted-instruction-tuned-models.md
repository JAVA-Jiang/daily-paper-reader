## 摘要
本研究提出了AiAWE，一个开源的自动写作评估系统，该系统使用LoRA适配的指令调优大型语言模型（Gemma-3-27B-it）对议论文进行评分。我们使用一个专有的教育考试服务中心（ETS）数据集，包含480篇托福独立写作作文，在120篇作文的训练子集上，以相同的LoRA配置对Gemma-3-27B和LLaMA-3.3-70B进行微调，并在相同的推理量化条件下对剩余360篇作文进行评估。微调后的Gemma模型实现了0.474的均方根误差、0.828的二次加权卡帕系数以及90.56%的评分一致性（与人工评分相差不超过±0.5），优于同一数据集上先前工作中报告的更大规模的LLaMA-3.3-70B模型和微调后的GPT-3.5基线。三个发现具有更广泛的意义：开放权重的大语言模型可以在基于评分标准的评分中达到或超过专有微调模型；模型规模并不能可靠地预测LoRA适配下的下游性能；相同的LoRA超参数在不同架构下会产生性质不同的适配行为。该系统运行于消费级服务器上，可通过https://app.awade.gec.waseda.ac.jp公开访问。LoRA适配器、应用程序代码和微调YAML文件可通过各自的存储库公开获取。

## Abstract
This study presents AiAWE, an open-source automated writing evaluation system that scores argumentative essays using a LoRA-adapted instruction-tuned large language model (Gemma-3-27B-it). Using a proprietary Educational Testing Service (ETS) dataset of 480 TOEFL Independent Writing essays, we fine-tune Gemma-3-27B and LLaMA-3.3-70B under identical LoRA configurations on a 120-essay training subset and evaluate on the remaining 360 essays under identical inference quantization. The fine-tuned Gemma model achieves a root mean square error of 0.474, a quadratic weighted kappa of 0.828, and an agreement rate of 90.56% within +/- 0.5 of the human score, outperforming both the larger LLaMA-3.3-70B model and the fine-tuned GPT-3.5 baseline reported in prior work on the same dataset. Three findings are of broader interest: open-weight LLMs can match or exceed proprietary fine-tuning for rubric-aligned scoring; model scale is not a reliable predictor of downstream performance under LoRA adaptation; and identical LoRA hyperparameters produce qualitatively different adaptation behaviors across architectures. The production system runs on a consumer-grade server and is publicly accessible at https://app.awade.gec.waseda.ac.jp. LoRA adapters, application code, and fine-tuning YAMLs are publicly available through their respective repositories.

### 1. 核心问题与整体含义（研究动机和背景）
- **背景**：自动写作评估（AWE）对教育至关重要，但传统人工评分费时费力且不一致。大型语言模型（LLM）提供潜力，但先前工作多依赖专有API（如GPT-3.5），存在数据主权风险（学生数据离开机构控制）、模型不可审计（权重保密、难以复现）以及成本/可持续性问题。
- **动机**：开发一个完全开源的AWE系统，使用开放权重LLM和本地部署，在评分质量上达到或超过专有模型，同时保证数据隐私和可复现性。
- **整体含义**：证明了开源权重LLM结合LoRA微调，可以在小样本数据集上获得与专有模型相媲美甚至更优的评分性能，消除了“质量 vs 数据主权”的权衡。

### 2. 方法论
- **核心思想**：使用参数高效微调（LoRA）适配指令调优模型，使其学会基于评分标准（rubric）输出分数，同时保留基础模型生成定性反馈的能力。训练时仅更新少量低秩适配器矩阵，推理时适配器与冻结的基础模型共同工作。
- **关键技术细节**：
  - **模型选择**：`google/gemma-3-27b-it`（27B参数）和 `meta-llama/Llama-3.3-70B-Instruct`（70B参数），均使用指令调优版本。
  - **LoRA配置**：rank `r=64`，scaling `α=128`（即 `α/r=2`），dropout=0，目标模块为注意力投影（q,k,v,o）和MLP投影（up,down,gate）。训练8个epoch，优化器AdamW，学习率5e-5，余弦调度，批量大小1，梯度累积8，精度bf16，最大序列长度2048 tokens。
  - **数据格式**：每个训练实例由系统提示（嵌入完整评分标准）、用户提示（作文题目+作文正文）和助手回答（仅数字分数，如“3.5”）组成。推理时生产提示请求JSON格式包含分数和结构化反馈（6个方面：表面错误、措辞、句子结构、任务完成、连贯与衔接、总体理由）。模型能自动生成反馈，因为基础模型的指令跟随能力被LoRA保留。
  - **推理量化**：使用GGUF Q4\_K\_M（约4-bit）量化，通过llama.cpp框架部署。Gemma-3-27B可单卡RTX 3090运行，LLaMA-3.3-70B需双卡RTX 3090分布式。
  - **双用途设计**：训练仅学习分数映射；推理时利用保存的基础能力生成结构化反馈，无需额外训练。

### 3. 实验设计
- **数据集**：ETS TOEFL Independent Writing数据集，共480篇议论文（两个题目各240篇），由专业ETS评分员按0-5整数/半整数评分。评分范围1.0-5.0。120篇训练（D120），360篇测试。
- **Benchmark**：Wang和Gayed (2024) 在相同数据集上微调GPT-3.5（turbo-1106）的结果，报告RMSE=0.573，QWK=0.78，±0.5一致率84.72%。
- **对比方法**：
  - Gemma-3-27B-it + LoRA（微调）
  - LLaMA-3.3-70B-Instruct + LoRA（微调，相同超参数）
  - GPT-3.5微调基线（来自文献）
- **评估指标**：RMSE、MAE、Pearson r、Spearman ρ、Quadratic Weighted Kappa (QWK)、±0.5一致率、精确一致率、分数偏误（每个分数等级的平均误差）。

### 4. 资源与算力
- **微调**：使用单张NVIDIA H200 SXM GPU（141GB VRAM），通过LLaMA-Factory框架运行。Gemma训练约2小时，LLaMA训练约5小时（均针对120篇训练集）。
- **推理**：本地工作站，AMD Threadripper 7955WX CPU + 双NVIDIA RTX 3090（每张24GB VRAM）。推理部署使用llama.cpp，Gemma单卡，LLaMA双卡tensor-split。推理延迟低于2秒/篇。
- **公开资源**：代码、LoRA适配器、训练YAML均公开；在线平台https://app.awade.gec.waseda.ac.jp可访问。

### 5. 实验数量与充分性
- **主要实验**：基于D120拆分（120训练/360测试）进行一次微调+评估，未报告多轮平均值（可能因数据量小，单次结果视为稳定）。此外训练了全480篇的生产模型，但未在held-out集评估。

- **充分性评价**：实验覆盖了一个数据集、一种任务（议论文评分）。对比了两种开源模型和一种专有基线，公平性设定合理（相同超参数、相同量化）。但缺少多数据集、多语言、公平性（跨L1组）、用户研究等。实验规模中等，结论可复现但泛化性受限。

### 6. 主要结论与发现
1. **RQ1**：开源权重LLM+LoRA可以匹配或超越专有模型：Gemma-3-27B在120训练集上获得RMSE 0.474、QWK 0.828、±0.5一致率90.56%，均优于GPT-3.5基线（0.573, 0.78, 84.72%）。
2. **RQ2**：模型规模并非预测性能的可靠指标：27B的Gemma在全部指标上优于70B的LLaMA（RMSE 0.474 vs 0.512, QWK 0.828 vs 0.777）。LLaMA表现出分数范围压缩（未预测低于2.0，5.0仅2次）。
3. **RQ3**：LoRA超参数并非模型无关：相同rank和配置下，LLaMA在rank>64时丧失反馈生成能力，而Gemma保持稳健。
4. **RQ4**：本地部署可行：Q4\_K\_M量化在消费级硬件上可实现实时评分，且质量未明显下降。

### 7. 优点
- **完全开源**：模型、适配器、代码、部署工具全部公开，可审计、可复现，数据主权受保护。
- **双用途设计**：单一微调模型同时支持高精度评分和详细定性反馈，无需额外训练。
- **资源友好**：27B模型单卡RTX 3090即可运行，微调仅需几个小时，门槛远低于全微调。
- **流程清晰**：统一使用llama.cpp和GGUF，量化方案一致，对比公平；训练和推理配置YAML化，便于复现。
- **平台实用**：已部署为生产级Web应用，支持课程管理、批量处理、自定义评分标准，具备实际使用价值。

### 8. 不足与局限
- **数据局限**：仅使用ETS 480篇TOEFL议论文（两个题目），覆盖狭窄：单一体裁、单一语域（成人L2英语学习者）、单一任务类型。对其他体裁（叙事、说明）或语言（非英语）的泛化性未知。
- **类别不平衡**：低分（1.0-1.5仅8篇）和高分（5.0仅39篇）样本极少，导致极端分数预测准确度和误差估计不稳定。
- **量化评估不足**：仅使用Q4\_K\_M，未比较不同量化方案（Q6\_K, Q8\_0等）对评分质量的影响；训练（全精度）与推理（4-bit）的精度不匹配未做系统分析。
- **LoRA rank敏感性未定量**：反馈生成丧失仅基于初步观察，缺少系统性的rank sweep和定量指标衡量。
- **公平性缺失**：未分析模型对不同母语组、性别等群体的评分偏差，不适合直接用于高风险评估。
- **无用户研究**：平台已部署，但未报告实际课堂效果、反馈对学生写作改进的影响或教师接受度。
- **生产模型未在held-out集评估**：全480篇训练的生产模型性能未知，只能引用D120拆分的评估结果。
