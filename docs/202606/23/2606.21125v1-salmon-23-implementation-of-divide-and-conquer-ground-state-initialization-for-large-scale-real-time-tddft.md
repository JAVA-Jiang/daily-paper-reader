## 摘要
在大规模实时含时密度泛函理论（TDDFT）中，基态电子结构的制备可能比随后的时间传播更为耗时，这限制了包含数千个原子的实际系统中非平衡电子动力学的模拟。这一瓶颈对于无序材料、液体、纳米结构和非均质凝聚态系统尤为重要，因为这些系统中的非线性及强场现象（如高次谐波产生和光致相变）需要显式的实时处理。SALMON是一个基于实空间网格实时TDDFT的光与物质相互作用模拟的开源第一性原理代码，支持结合MPI与OpenMP或GPU加速的大规模并行计算。在SALMON 2.3中，我们实现了一种分治密度泛函理论（DC-DFT）方案，并将其与一种重建整个系统空间扩展Kohn-Sham轨道的后处理方法相结合。这些重建的全局轨道直接用作SALMON标准实时实空间TDDFT模块的初始状态。所得到的工作流程将高效的DC-DFT基态制备与传统的实时TDDFT连接起来。DC-DFT自洽场过程表现出与系统尺寸的线性标度，解决了大规模电子动力学模拟中的一个主要瓶颈，同时保留了SALMON既定时间传播方案的鲁棒性和广泛适用性。我们描述了计算过程、并行化策略和输入/输出设计。在Fugaku上使用Si超胞的弱扩展测试证实了线性标度行为。对512原子非晶硅系统和包含4134原子的体相H2O液态系统的精度测试表明，该工作流程能够实现实用的大规模实时TDDFT模拟。

## Abstract
In large-scale real-time time-dependent density functional theory (TDDFT), preparing the ground-state electronic structure can be more expensive than the subsequent time propagation, limiting simulations of nonequilibrium electron dynamics in realistic systems containing thousands of atoms. This bottleneck is especially important for disordered materials, liquids, nanostructures, and heterogeneous condensed-matter systems, where nonlinear and strong-field phenomena such as high-harmonic generation and light-induced phase transitions require explicit real-time treatment.   SALMON is an open-source first-principles code for light-matter interaction simulations based on real-time TDDFT on real-space grids, supporting massively parallel calculations with MPI combined with OpenMP or GPU acceleration. In SALMON 2.3, we implement a divide-and-conquer density functional theory (DC-DFT) scheme and combine it with a postprocessing method that reconstructs spatially extended Kohn-Sham orbitals of the entire system. These reconstructed global orbitals are used directly as initial states for the standard real-time, real-space TDDFT module of SALMON.   The resulting workflow connects efficient DC-DFT ground-state preparation to conventional real-time TDDFT. The DC-DFT self-consistent-field procedure exhibits linear scaling with system size, addressing a major bottleneck in large-scale electron-dynamics simulations while retaining the robustness and broad applicability of SALMON's established time-propagation scheme. We describe the computational procedure, parallelization strategy, and input/output design. Weak-scaling tests using Si supercells on Fugaku confirm the linear-scaling behavior. Accuracy tests for a 512-atom amorphous Si system and a bulk H2O liquid system containing 4134 atoms demonstrate that the workflow enables practical large-scale real-time TDDFT simulations.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在大规模实时含时密度泛函理论（TDDFT）模拟中，基态电子结构的制备（传统DFT）计算复杂度为 O(N³)，而时间传播复杂度为 O(N²)。对于包含数千至数万个原子的实际系统（如无序材料、液体、纳米结构、异质凝聚态系统），基态准备的计算成本往往超过时间传播，成为模拟非平衡电子动力学的主要瓶颈。
- **整体含义**：现有线性标度DFT方法（如基于局域轨道的方法）在强场、强非线性激发下可能遇到基组收敛性问题。因此，需要一种既能高效制备基态、又能兼容标准实空间实时TDDFT（适用于强场）的实用方案。论文通过实现分治DFT（DC-DFT）并结合后处理重建全局Kohn-Sham（KS）轨道，成功将线性标度的基态准备与SALMON中成熟的实时实空间TDDFT框架集成，从而解决了该瓶颈，扩展了大规模强场动力学模拟的能力。

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 核心思想
- 基于电子物质的近邻性（nearsightedness）原理，将系统划分为相互重叠的碎片（fragments），每个碎片独立求解局部KS方程，总电子密度由碎片贡献组装，从而将SCF过程降至 O(N) 复杂度。
- 后处理阶段：利用碎片构造一组紧凑的正交基函数（DC-LCFO），在此基础上组装全体系的简化哈密顿矩阵并进行对角化，重建全局KS轨道，作为标准实时TDDFT的初始态。

### 关键技术细节
- **碎片分解**：整个模拟单元被划分为规则网格的核区域（core regions），每个核区域向外扩展缓冲层（buffer thickness b），形成重叠的碎片 Ωα。缓冲层厚度 b 是控制精度与效率的关键参数。
- **碎片KS方程**：在每个碎片内求解局部KS方程：Ĥα φᵅᵢ(r) = εᵅᵢ φᵅᵢ(r)。总密度 ρᵗᵒᵗ(r) = Σα ρ̄ᵅ(r)，其中 ρ̄ᵅ(r) 为碎片密度在核区域的投影。
- **DC-LCFO重建**：
  1. 选取碎片中能量低于截断 εₖᵤₜ 的轨道，投影到核区域。
  2. 每个碎片内构造重叠矩阵并对角化，舍弃特征值小于 λₖᵤₜ 的冗余分量，得到一组正交基函数 {λᵅᵢ(r)}，局域于核区域但整体正交。
  3. 在整个系统的正交基下组装哈密顿矩阵 ⟨λᵅᵢ|Ĥ|λᵅ'ᵢ'⟩（近邻碎片间需通信），对角化得到全局KS轨道系数。
- **工作流**：DC-DFT SCF循环 → DC-LCFO后处理 → 重建全局轨道 → 输入标准实空间实时TDDFT（或常规DFT）模块。
- **输入参数**：通过 &dc namelist 指定碎片数、缓冲网格点数、碎片轨道数、截断参数等。并行配置支持MPI进程分布（碎片、轨道、实空间网格三级分解）。

### 算法流程（文字说明）
1. 初始化：系统划分碎片，设置缓冲层；每个碎片独立初始化电子密度。
2. SCF循环：并行求解各碎片KS方程，计算碎片密度并投影到核区域，组装总密度；求解全局Poisson方程得到Hartree势；更新碎片Hamiltonian；重复至收敛。
3. 后处理（DC-LCFO）：从碎片轨道构建正交基函数；组装全体系哈密顿矩阵（近邻通信）；对角化得到全局KS轨道系数；输出基函数数据和系数文件。
4. 后续使用：读入重建的全局轨道，作为标准实时TDDFT或常规DFT的初始态。

## 6. 论文的主要结论与发现

1. **线性标度证实**：DC-DFT SCF循环在Fugaku上表现出线性标度行为，与常规DFT的O(N³)形成对比；在512原子处交叉，更大系统DC-DFT显著更快。
2. **精度评估**：
   - 对于强场激发（10¹²-10¹³ W/cm²），DC-DFT初始态给出的电流、激发能、高次谐波谱与常规DFT高度一致，适用于实用分析。
   - 在弱场线性响应下，DC-DFT密度误差导致激发能偏移和高次谐波高频噪声；通过增大缓冲厚度或使用固定密度DC可消除。
   - DC-LCFO重构本身精度足够，误差主要源于DC-DFT SCF密度收敛不足。
3. **实际加速**：液态水系统基态准备从4.3小时降至3分钟（加速约86倍），文件大小从170 GB降至20 GB。
4. **工作流实用性**：提供三种使用模式（直接实时TDDFT、加速常规DFT+TDDFT、固定密度DC），适应不同精度/存储需求。
5. **优势保留**：该方法保留了实空间有限差分实时TDDFT框架，兼容强场和非线性模拟。

## 8. 不足与局限

- **实验覆盖**：仅测试了Si（共价固体）和H₂O（分子液体），未涉及金属、异质界面、纳米结构等；未展示>1.5万原子的精度验证；所有模拟均使用Γ点，k点采样未实现。
- **方法论局限**：

  - 精度依赖缓冲厚度，最优选择需经验或预测试，缺乏自动选择机制。

- **应用限制**：对于弱场线性响应或高频噪声敏感的分析，需要额外DFT迭代或固定密度DC，增加了步骤；k点缺失限制了能带结构计算。
