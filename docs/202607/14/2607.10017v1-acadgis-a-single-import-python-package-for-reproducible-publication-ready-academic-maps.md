## 摘要
学术和项目地图通常通过碎片化的工作流程制作：研究人员定位边界、管理shapefile、连接表格数据、组装定位插图、添加制图装饰，并通过桌面GIS或多包Python脚本导出图形。这给非GIS用户造成了访问障碍，并且当数据源、样式选择和手动编辑未以可执行形式捕获时，会产生可复现性问题。我们提出AcadGIS，一个免费开源Python包，通过一个命名空间下的高级命令创建面向出版的研究地图，即 import acadgis as agis。AcadGIS提供地名边界访问、自动研究区域定位布局、专题制图、栅格和矢量图层、精选的地球观测产品、地形和水文背景，以及可配置的PNG、PDF和SVG导出，无需桌面GIS专业知识或手动管理shapefile。其设计结合了单导入访问科学Python栈、面向出版的默认设置与渐进式控制、本地缓存、来源归属，以及基于代码、命名数据和固定包版本的图形规范。通过三个代表性用例，我们展示了常见的论文、论文和项目地图如何表示为紧凑、可检查的脚本。源代码：https://github.com/riponcm/AcadGIS。

## Abstract
Academic and project maps are often produced through a fragmented workflow: researchers locate boundaries, manage shapefiles, join tabular data, assemble locator insets, add cartographic decorations, and export figures through desktop GIS or multi-package Python scripts. This creates an accessibility barrier for non-GIS users and a reproducibility problem when data sources, styling choices, and manual edits are not captured in executable form. We present AcadGIS, a free and open-source Python package that creates publication-oriented research maps from high-level commands under one namespace, import acadgis as agis. AcadGIS provides place-name boundary access, automated study-area locator layouts, thematic cartography, raster and vector layers, curated Earth-observation products, terrain and hydrology context, and configurable PNG, PDF, and SVG export without requiring desktop GIS expertise or hand-managed shapefiles. Its design combines one-import access to the scientific-Python stack, publication-oriented defaults with progressive control, local caching, source attribution, and figure specifications based on code, named data, and a pinned package version. Through three representative use cases, we demonstrate how common paper, thesis, and project maps can be expressed as compact, inspectable scripts. Source code: https://github.com/riponcm/AcadGIS.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- **单导入工作流**：通过一个命名空间 `import acadgis as agis` 即可使用所有功能，并重新导出科学栈（`agis.plt`, `agis.gpd`, `agis.pd` 等），简化代码。
- **出版导向默认设置 + 渐进式控制**：常见地图类型（如研究区定位图、分级统计图、地形图、卫星影像图等）预设合理默认值；用户可通过布尔值、命名选项、字典三种粒度进行精细调整。
- **可复现规范**：地图由代码、命名数据、固定包版本、本地缓存和显式来源归属共同定义，避免手动操作导致的不可复现。

### 关键技术细节
1. **行政边界与模糊名称匹配**：
   - `load_boundaries(country, level, within=...)` 按国家名和行政级别返回 GeoDataFrame，支持按父级区域过滤（如“division 内的 district”）。孟加拉国、伊拉克、印度、美国边界内置本地；其他地区从 GADM 按名下载并缓存。
   - 模糊匹配（`match_one`, `match_table`，基于 rapidfuzz）处理地名变体、变音符号等，避免静默丢弃未匹配记录。
2. **研究区定位图**：
   - `StudyArea` 构建器和 `study_area` 函数：通过行政层级表达式（如 `["division", "Dhaka"]`, `["district", "Gazipur"]`）自动生成嵌套面板、连接框、箭头、标签、比例尺、指北针等。五种模板：`single`、`two`、`cascade`、`series`、`grid`。
3. **专题地图目录**：
   - 覆盖常见静态专题地图类型：choropleth（分级统计图，支持 mapclassify 分类）、graduated symbols、heatmap、isopleth/contours（基于 NumPy 高斯核插值）、dot-density、bivariate（3×3 颜色矩阵）、cartogram（Dorling 和非连续型）、proportional symbols。
4. **栅格与矢量层**：
   - `add_raster`：绘制 GeoTIFF（连续、分类或 RGB），自动重投影。
   - `add_basemap` / `add_satellite`：通过 contextily 和 xyzservices 添加底图。
   - `add_landcover`：读取 ESA WorldCover（10m 分辨率，窗口化 COG）。
   - `add_ndvi`：从 Earth Search STAC 目录查询最清晰 Sentinel-2 场景，窗口读取红和近红外波段，计算 NDVI，无需 API key。
5. **地形与水文学**：
   - `load_dem`：获取 Copernicus GLO-30 DEM 贴片。
   - `relief`：渲染山体阴影与高度着色。
   - `drainage` / `add_streams`：利用 pysheds 从 DEM 计算汇流累积并绘制河网。
6. **导出与样式**：
   - `agis.save(obj, path, dpi=300)` 支持 PNG、PDF、SVG。
   - 装饰（指北针、比例尺、边框、经纬网、图例、标签）均可通过布尔值、命名或字典配置。

### 算法流程（文字说明）
1. 用户提供地图规格：地名/边界、可选表格或栅格、地图类型、样式选项。
2. AcadGIS 内部：边界与缓存服务获取/加载几何数据；匹配服务将用户表格按地名模糊连接；地图构造器创建指定模式（posi图、专题图、地形图等）；样式与导出服务应用默认值并输出。
