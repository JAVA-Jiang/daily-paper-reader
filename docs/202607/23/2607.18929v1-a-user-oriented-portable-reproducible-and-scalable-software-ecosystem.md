## 摘要
科学家通常在多样化的硬件上进行研究，从笔记本电脑和工作站到超级计算机和云资源。标准场景需要混合使用这些资源。本文描述了一个软件生态系统，使用户能够依赖相同的开发环境在不同计算资源上运行其工作流程。我们描述了一个模块化的统一命令行界面，允许跨不同硬件平台与用户工作流程进行交互。该软件生态系统已在plan4res EU H2020项目中成功测试。它可以扩展到具有类似需求的其他项目，使其能够受益于同一方法来执行计算工作流程。

## Abstract
It is normal for scientists to perform their research on a diverse set of hardware, ranging from laptops and workstations to supercomputers and cloud resources. The standard scenario requires a mix of these resources. In this paper we describe a software ecosystem that enables users to rely on the same development environment for running their workflows across the different computational resources. We describe a modular, unified command-line interface that allows for the interaction with a user-workflow across diverse hardware platform. The software ecosystem has been successfully tested as part of the plan4res EU H2020 project. It can be extended to other projects with similar requirements, so that they can benefit from the same approach for executing computational workflows.
