## 摘要
我们研究经典的单机截止时间问题 $1 \mid\mid \sum U_j$，其中每个任务具有截止时间和执行需求，目标是尽可能多地选择按时完成的任务。标准的Moore-Hodgson算法按截止时间处理任务，并可能随后删除先前已接受的任务。我们研究Lin和Wang的仅插入最短作业优先规则：按执行需求非递减顺序处理任务，并在保持可行性的条件下接受任务。我们给出一种直接的$O(n\log n)$时间实现，使用基于截止时间键值的平衡增强二叉搜索树。与该SJF规则的先前$O(n\log n)$实现不同，我们的实现既不需要抢占式调度，也不需要区间变化的摊销分析。我们的分析给出了该规则的字典序（\emph{字典优先}）最优性的显式阈值形式：对于每个阈值~$e$，其输出最大化所选任务中执行需求不超过~$e$的任务数量。该分析还揭示了额外的组合结构。在较短的任务被贪心地固定后，单个执行需求层级内的可行选择形成一个嵌套拟阵。这些层级拟阵作为直和，组合成一个整体层状拟阵，其基恰好是贪心输出。最后，编码截止时间-前缀约束的流网络为底层调度可行性结构给出了多拟阵秩函数。这种流视角也恢复了控制相等执行层级的嵌套拟阵。

## Abstract
We study the classical single-machine deadline problem $1 \mid\mid \sum U_j$, in which each task has a deadline and an execution requirement and the goal is to select as many on-time tasks as possible. The standard Moore-Hodgson algorithm processes tasks by deadline and may later delete a previously accepted task. We study the insertion-only shortest-job-first rule of Lin and Wang: process the tasks in nondecreasing execution requirement, and accept a task exactly when doing so preserves feasibility. We give a direct $O(n\log n)$-time implementation using a balanced augmented BST keyed by deadline. Unlike the previous $O(n\log n)$ implementation of this SJF rule, our implementation needs neither a preëmptive schedule nor an amortized analysis of interval changes.   Our analysis gives an explicit threshold form of the rule's lexicographic (\emph{lex-first}) optimality: for every threshold~$e$, its outputs maximize the number of selected tasks whose execution requirement is at most~$e$. The analysis also reveals additional combinatorial structure. After the shorter tasks have been greedily fixed, the feasible choices within a single execution-requirement tier form a nested matroid. These tier matroids assemble, as a direct sum, into an overall laminar matroid whose bases are exactly the greedy outputs. Finally, a flow network encoding the deadline-prefix constraints gives a polymatroid rank function for the underlying scheduling feasibility structure. This flow view also recovers the nested matroids that govern the equal-execution tiers.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题**：经典单机调度问题 $1 \mid\mid \sum U_j$，有 $n$ 个非抢占任务，每个任务有正执行需求（长度）和正截止时间，所有任务在时间 0 可用。目标是选择一个最大基数的子集，使其所有任务按时完成（即最小化延迟任务数）。
- **已有方法**：
  - **Moore-Hodgson 算法**：按截止时间递增处理任务，接受任务，若超出时限则删除已接受任务中执行需求最大的一个。需要删除操作。
  - **Lin 和 Wang 的插入式 SJF 规则**：按执行需求非递减顺序处理，仅当插入后保持可行性才接受，从不删除已接受的任务。该规则简单但直接实现 $O(n^2)$。Zhao 和 Yuan 给出了第一个 $O(n \log n)$ 实现，但需要维护一个抢占式反向调度（DD-区间族）和摊销分析。
- **本文动机**：简化插入式 SJF 规则的实现，避免复杂的抢占式调度和摊销分析，同时揭示其深层组合结构（字典序最优性、拟阵性）。

### 2. 论文提出的方法论

- **核心思想**：使用平衡增广二叉搜索树（BST），按截止时间作为键值。每个节点存储该截止时间下的总执行需求，并维护两个字段：子树总执行需求 $x$ 和子树内的最小截止时间-前缀松弛时间 $y$（即 $\min_{v \in \text{subtree}} (v.d - \sum_{v' \le v} v'.e)$）。树可行 $\iff$ 根节点的 $y \ge 0$。
- **算法流程**（Algorithm 1，SJF-Greedy）：
  1. 对所有任务按执行需求非递减排序（相同长度任意打破平局），得到 SJF 顺序 $\sigma$。
  2. 初始化空集 $X$ 和空 BST $T$。
  3. 遍历 $\sigma$ 中的每个任务 $\alpha$：
     - 先将 $(\alpha.d, \alpha.e)$ 插入 $T$（检测插入后是否可行）。
     - 若 `T.feasible()` 返回真（即根节点 $y\ge 0$），保留插入，将 $\alpha$ 加入 $X$。
     - 否则，执行回滚删除操作（移除刚刚插入的结点）。
  4. 返回 $X$。
- **关键技术细节**：
  - 利用引理 2.3（单任务插入可行性条件）：$X+\alpha$ 可行 $\iff$ $\text{slack}(X, \alpha.d) \ge \alpha.e$，其中 $\text{slack}(X,d)$ 是 $d$ 之后所有截止时间前缀的最小间隙。
  - 树节点 $u$ 的 $y$ 字段计算公式：$u.y = \min\{y_L,\; u.d - x_L - u.e,\; y_R - x_L - u.e\}$，其中 $x_L,y_L$ 为左子树字段，$x_R,y_R$ 为右子树字段。可在 $O(1)$ 时间内更新。
  - 每个候选任务最多一次插入、一次根测试、一次回滚删除，最坏情况 $O(\log n)$，总时间 $O(n \log n)$。
- **理论结构**：
  - **字典序最优性**（Lemma 5.5）：贪心输出集 $X$ 满足：对任意阈值 $e$，$|X_{\le e}|$ 是所有可行子集中的最大值（即“执行需求前缀占优”），等价于 Lin-Wang 定义的字典序最小处理时间序列。
  - **层级正交性**（Lemma 5.8）：每个执行需求层（长度相同）的贪心选择独立于其他层和该层内部顺序。所有贪心输出 = 各层可能选择的笛卡尔积。
  - **拟阵解释**：
    - 每个长度层 $e$ 构成一个**嵌套拟阵**（Nested Matroid），其独立集由一组链约束 $|Y \cap D_k| \le b_k$ 定义（Theorem 6.8）。其中 $D_k$ 是按截止时间排序的前缀集合，$b_k$ 是经下层贪心集 $A$ 调整后的容量上限。
    - 所有层直和得到整体**层状拟阵**（Laminar Matroid），其基恰好是所有贪心输出（Lemma 6.3）。
  - **流网络视角**（Section 7）：构建一个从源点到任务节点再到时间段节点的流网络，最大流值等于 $F^*_S(X) = \min_\ell (d_\ell + \sum_{\alpha \in X, \alpha.d > d_\ell} \alpha.e)$。可行 $\iff$ 流等于总执行需求。该秩函数是归一化、单调、子模的，构成多拟阵（Polymatroid）。
