## 摘要
xDECAF是一个基于架构的数据流分析的可扩展工具，专注于信息安全。它结合了带有标记流和节点的扩展数据流图元模型、具有不同流操作的领域特定约束语言，以及由分析引擎驱动的基于浏览器的编辑器。在本文中，我们介绍了xDECAF工具库和包含20多个示例模型的精选目录，这些模型带有记录的约束和预期的违规，旨在作为社区可重复使用的数据集。该工具已被多个研究路线采用，提供了其有用性的具体证据。该工具、数据集以及托管的在线编辑器可公开获取。

## Abstract
xDECAF is an extensible tool for architecture-based data flow analysis with a focus on information security. It combines an extended data flow diagram metamodel of labeled flows and nodes, a domain-specific constraint language with different flow operations, and a browser-based editor backed by an analysis engine. In this paper, we present the xDECAF tool library and a curated catalog of over 20 example models with documented constraints and expected violations, intended as a reusable dataset for the community. The tool has already been adopted by several research lines, providing concrete evidence of its utility. The tool, dataset, and a hosted online editor are publicly available.

### 2. 方法论：核心思想与关键技术细节

- **核心思想**：基于扩展的数据流图（DFD）元模型，支持标签（Labels）、引脚（Pins）和赋值（Assignments），实现标签的传播与分析；提供领域特定约束语言（DSL）来定义数据流约束，并通过独立分析每个数据流来检测违规。
- **关键技术细节**：
  - **扩展DFD元模型**：节点和流可附加标签（表示属性或元信息），节点有输入/输出引脚，流从输出引脚到输入引脚。赋值定义输出引脚如何根据输入标签计算传播后的标签。
  - **标签传播引擎**：自动计算所有可能的标签传播路径，支持循环图的启发式处理。
  - **约束语言（DSL）**：结构为 `<源> <流动词> <目标> [where <条件>]`，支持四种流动词（flows, alwaysFlows, neverFlows, notAlwaysFlows），对应存在量词与全称量词及其否定。条件部分支持变量绑定和集合运算（如交集、大小比较），可表达复杂的访问控制规则（如基于角色的约束）。
  - **算法流程**：用户构建或导入DFD → 定义标签和赋值 → 执行标签传播 → 用户编写约束 → 引擎对每个独立数据流评估约束 → 输出违规情况及传播后的标签信息。
  - **工具链**：提供Java库（支持扩展和集成）、基于Sprotty的前端编辑器（拖拽建模、语法高亮、自动补全）、WebSocket通信的后端分析引擎。
