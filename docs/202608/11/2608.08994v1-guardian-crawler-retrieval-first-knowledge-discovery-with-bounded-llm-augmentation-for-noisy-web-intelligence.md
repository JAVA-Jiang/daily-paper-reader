## 摘要
从嘈杂的网络数据中检索相关证据颇具挑战，尤其是在包含不完整报告、异质语言和无关内容的敏感领域。我们提出了Guardian Crawler，一个可复现的检索优先测试平台，用于在合成类网络语料库上进行受控的知识发现和基于证据的摘要实验。该架构将BM25检索与风险感知、嵌入增强及混合重排序相结合，随后进行带显式文档引用的受限检索增强生成。在包含900篇文档的合成语料库和10个查询上的实验中，基于风险的重排序取得了最高的描述性检索分数，P@10 = 1.00，NDCG@10 = 0.94，而BM25的相应值为0.94和0.81。最佳混合配置和BM25+语义配置的NDCG@10分别达到0.94和0.88。所有41个可评估的生成条目均通过了词汇覆盖率阈值；自动化LLM评判将其中36个归类为有依据，1个为部分有依据，4个为无依据。这些结果表明Guardian Crawler作为受控测试平台的可行性，但并未确立统计优越性、人工验证的忠实性或向实时网络调查环境的迁移能力。

## Abstract
Retrieving relevant evidence from noisy web data is challenging, particularly in sensitive domains containing incomplete reports, heterogeneous language, and irrelevant content. We present Guardian Crawler, a reproducible retrieval-first testbed for controlled experiments on knowledge discovery and evidence-grounded summarization over synthetic web-like corpora. The architecture combines BM25 retrieval with risk-aware, embedding-augmented, and hybrid reranking, followed by constrained retrieval-augmented generation with explicit document citations. Experiments on a synthetic 900-document corpus and 10 queries produced the highest descriptive retrieval scores under risk-based reranking, with P@10 = 1.00 and NDCG@10 = 0.94, compared with 0.94 and 0.81 for BM25. The best hybrid and BM25+Semantic configurations reached NDCG@10 values of 0.94 and 0.88, respectively. All 41 evaluable generated bullets passed the lexical coverage threshold; an automated LLM judge classified 36 as supported, one as partially supported, and four as unsupported. These results demonstrate the feasibility of Guardian Crawler as a controlled testbed but do not establish statistical superiority, human-validated faithfulness, or transfer to live-web investigative environments.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- **检索优先架构**：先通过可解释的词汇检索（BM25）获取候选文档，再进行重排序，最后在受约束的检索增强生成（RAG）阶段生成带引用的摘要。LLM 被严格限制在语料构建、文档标记、摘要生成和自动评估等辅助角色中，不参与核心检索决策，避免成为端到端的黑箱生成模型。
- **模块化与可复现性**：系统由配置层、迷你网络生成器、HTML 提取器、爬虫、BM25 索引、标记层、风险重排序器、语义重排序器、排名运行器、RAG 层和评估层组成的模块化端到端管线。

### 关键技术细节
- **合成语料生成**：从结构化案例种子生成静态 HTML 语料，页面分为四类：公告（bulletin）、新闻（news）、噪声（noise）和无关（irrelevant）页面；通过集线页面和合成超链接形成可爬取的图结构，具有同类型链接偏向性和可达性保证。
- **检索与重排序**：
  - BM25 作为唯一的第一阶段检索器，对所有 900 篇文档进行初筛，候选池固定为全部语料（900 篇），确保后续重排序仅反映评分/排序差异而非召回差异。
  - 风险感知重排序：基于 28 条危害相关词条词典，对文档的风险原始分数计算后映射到有界区间。
  - 嵌入语义重排序：采用离线预计算的文档嵌入，计算查询-文档的归一化语义相似度作为第二阶段的排序信号。
  - 混合重排序：线性组合词汇、风险、语义三类信号。
- **有界 LLM 角色**：Gemini 承担四个角色——语料构建、页面标记（JSON schema 约束）、带引用的摘要生成（仅接收选定证据段落，输出受限条数且可弃权）和自动支撑评判（区分 supported / partially_supported / unsupported）。

### 关键公式
- **BM25 的 IDF 计算**：IDF = log((N - df + 0.5) / (df + 0.5) + 1)，其中 N 为文档总数（900），df 为包含该词的文档数。BM25 参数为 k1 = 1.2，b = 0.75，min_doc_tokens = 3。BM25 对查询中的去重词元（query terms treated as set）逐项求和。
- **风险原始分**：RiskRaw(d) = Σ_t w_t · min(tf_t(d), 2)，即每个词条在标题和正文中的计数最高截断到 2。
- **有界风险分**：RiskScore(d) = RiskRaw(d) / (RiskRaw(d) + 3)，将风险分数映射到 [0, 1] 区间。
- **归一化**：BM25 分数在候选池内做 min-max 归一化（记为 BM25̂）；风险分数本身已在 [0,1] 内。
- **风险重排评分**：Score_risk(d, q) = (1 - α) · BM25̂(d, q) + α · Risk(d)
- **语义重排评分**：Score_sem(d, q) = (1 - λ) · BM25̂(d, q) + λ · Sem̂(d, q)，其中 Sem̂ 是归一化的嵌入相似度。
- **混合重排评分**：Score_hybrid(d, q) = w_B · BM25̂(d, q) + w_R · Risk(d) + w_S · Sem̂(d, q)，其中权重三元组（w_B, w_R, w_S）在实验中取 (0.6, 0.2, 0.2)、(0.5, 0.25, 0.25)、(0.4, 0.3, 0.3)。

- **检索效果**：在同一候选池（全语料）前提下，BM25 + Risk（α = 1.0）获得了最高的宏平均 P@10 = 1.00 和 NDCG@10 = 0.94，优于 BM25 基线的 (0.94, 0.81)；最佳混合配置 (0.4, 0.3, 0.3) 达到 (0.99, 0.94)；最佳语义配置（λ = 0.6）达到 (0.97, 0.88)。
- **语义诊断**：BM25 + Semantic 在 SR@10 上最高（λ = 0.6 时为 0.57），超过 BM25 和风险重排配置——语义重排在主要检索指标上未超过风险重排，但语义对齐性更好，表明词汇信号与语义信号捕捉了排序的部分不同特征。
- **生成支撑**：全部 41 个可评估条目通过确定性词汇覆盖率阈值（100% 词汇支撑），但 LLM 评判仅认定 36 个为 fully supported（87.8% 严格支撑率），1 个为部分支撑，4 个为无支撑（9.8% 无支撑率）；多数问题出现在多跳推理（multi-hop inference）和证据不在引用文本中（not_in_evidence），表明词汇重叠不足以保证语义忠实性。
- **总体判断**：Guardian Crawler 作为受控测试平台是可行的，但结果属于描述性结论，不能外推为统计优势、人工验证的忠实性或实时网络调查有效性。

## 7. 优点

- **可复现性强**：整个流程通过统一评估管线自动化完成（qrels 生成、重排对比、检索与支撑评估），配置明确、参数公开，便于他人复现。
- **架构模块化**：检索、重排序、标记、嵌入、生成、评估各环节独立可替换，便于进行针对性消融和模块替换研究。
- **有界 LLM 使用**：将 LLM 限定在辅助任务（语料构建、标记、生成、评判），避免了端到端神经检索的黑箱问题，同时以显式引用的受限生成保持可审计性。
- **评估分离设计**：将检索有效性和生成支撑性分开评估，并引入词汇与 LLM 评判双重检查，能显式暴露“词汇覆盖 ≠ 语义支撑”的问题，设计认识优于单一“RAG 质量”标量。
- **共享候选池**：所有重排序作用于同一 BM25 候选列表，隔离了重排序行为本身的影响，使得对比归因相对清晰。
- **设计落地性强**：先过滤后重排的检索优先理念符合现实搜索引擎架构直觉，且针对风险信号和安全敏感领域的应用背景有明确现实意义。

## 8. 不足与局限

- **语料为合成而非真实**：无法复现真实网页的漂移、对抗性内容、坏标记、多语言变化和信息生态演化，结果须视为受控实验而非真实运行性能。
- **规模过小**：仅 900 篇文档和 10 条查询，对宏观统计的稳定性不利，限制了查询语义多样性和泛化能力；作者也承认这一局限。
- **领域特异性强**：风险词典、查询集和文档类型均针对失踪儿童 / 人口贩卖领域定制，风险重排在跨领域时的表现无法保证。
- **生成器与风险词典可能引入偏差**：文档类型分布、模板风格、链接结构等选择会影响检索环境；风险词典可能过度强调某些词汇而忽略其他；“qrels 规则”与“风险词典”编码了相似的领域线索，其未量化的重叠可能部分有利于风险重排。
- **LLM 评判不可靠**：评判本身存在模型特有脆弱性、提示敏感性和分类偏差，且 Gemini 同时参与多个环节，仅做到了程序分离而非模型族独立，缺乏人类标注验证。
- **缺乏统计推断**：未做显著性检验、置信区间或置换检验，宏平均差异可能仅是抽样噪声。
- **生成层存在案例混淆风险**：跨文档综合时容易将词法相似但事实不同的案例混淆，这是证据化摘要的核心挑战之一，文中已观察到此类失败。
- **不涉及下游决策**：系统未验证搜索计划、干预结果或真实调查效果，尚不能证明与真实调查工作流的集成价值。
