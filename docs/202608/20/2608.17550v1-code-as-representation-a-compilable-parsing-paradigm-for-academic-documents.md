## 摘要
学术论文是科学知识的主要载体，但大多数知识仍锁定在优化用于人类阅读而非机器使用的PDF中。对于多模态大语言模型（MLLMs），核心挑战不仅在于感知，还在于表示：科学页面将文本与结构化学术元素（SAEs）交织在一起，如表格、公式、图表和伪代码，而这些元素的结构、数据和逻辑在Markdown等常见替代格式中难以保留。因此，我们提出可编译学术文档解析（CADP）范式，该范式将整个页面重建为上下文\LaTeX{}加可执行Python，从而能够重建、重新编译结构保持元素和可执行图表表示，并直接对照源页面进行验证。为支持这一设置，我们引入了CADP-Bench，一个专家验证的基准测试，涵盖包含紧密耦合文本和多种SAE类型的完整学术页面，并通过重新注入编译协议进行评估。我们进一步使用SOTA MLLMs和一个结合了常见智能体技术的探索性多智能体基线来研究当前能力。结果表明，即使是最前沿的模型，在生成高保真可执行重建方面仍然困难重重，凸显了在结构感知科学文档解析方面仍有很大的改进空间。CADP-Bench已发布以供未来研究使用。

## Abstract
Academic papers are a primary carrier of scientific knowledge, yet most of this knowledge remains locked in PDFs that are optimized for human reading rather than machine use. For Multimodal Large Language Models (MLLMs), the core challenge is not only perception, but representation: scientific pages interleave text with Structured Academic Elements (SAEs) such as tables, formulas, charts, and pseudocode, whose structure, data, and logic are poorly preserved by common surrogates like Markdown. We therefore propose Compilable Academic Document Parsing (CADP), a paradigm that reconstructs a full page as contextual \LaTeX{} plus executable Python, so that structure-preserving elements and executable chart representations can be reconstructed, recompiled, and directly verified against the source page. To support this setting, we introduce CADP-Bench, an expert-verified benchmark of full academic pages containing tightly coupled text and multiple SAE types, evaluated through a re-injection compilation protocol. We further study current capabilities using SOTA MLLMs and an exploratory multi-agent baseline that incorporates common agentic techniques. Results show that even frontier models still struggle to produce high-fidelity executable reconstructions, highlighting substantial room for improvement in structure-aware scientific document parsing. CADP-Bench is released for future research.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题根源**：学术论文是科学知识的主要载体，但大部分知识被"锁"在面向人类阅读而非机器使用的 PDF 中。多模态大语言模型（MLLMs）要处理科学页面时，核心挑战不仅是感知（perception），更是表示（representation）。
- **结构化元素的困境**：学术页面将连续文本与表格、公式、图表、伪代码等**结构化元素（SAEs，Structured Academic Elements）**紧密交织。现有流程通常将页面图像转成 Markdown，但 Markdown 存在三大根本缺陷：
  1. **结构坍塌（structural collapse）**：扁平语法无法清晰编码合并表格、对齐公式或复杂伪代码；
  2. **图表不透明（chart opacity）**：图表被降级为静态裁剪图像，丢失底层数据和渲染逻辑；
  3. **不可验证（non-verifiability）**：解析出的扁平文本无法重新编译以视觉验证与原始文档的一致性。
- **核心思想转向**：能否从页面像素中恢复一种既保留结构、又暴露图表数据与渲染逻辑、还能编译回忠实页面渲染的表示？作者认为可以，并主张将解析从"像素到文本"重构为"像素到程序"。

## 2. 方法论：核心思想、技术细节与评估协议

### 2.1 CADP 任务形式化
- **输入**：目标页面图像 $I_p$（$H \times W \times 3$）+ 有限的编译上下文 $C_{pkg}$（文档模板中的包声明）。模型**不**获得源上下文 $C_{\backslash p}$（原文 LaTeX 中移除第 p 页内容后的部分）。
- **输出**：双代码（Dual-Code）生成，学习目标 $f_\theta: (I_p, C_{pkg}) \to (L_p, P_p)$：
  - **上下文 LaTeX 块（$L_p$）**：重建页面文本、表格、公式、伪代码及其结构；
  - **可执行 Python 程序（$P_p = \{P_1, ..., P_k\}$）**：为页面上 $k$ 个图表生成可运行的绘图代码，编码从图像中视觉推断出的量化数值与渲染逻辑。

### 2.2 数据集构建流程（CADP-Bench）
1. **数据采集**：从 arXiv 大规模采集 PDF 与对应 LaTeX 源文件，覆盖多个学科；
2. **PDF 解析**：用 Mineru 框架进行页面级布局分析，识别表格、图表、公式、伪代码等元素；
3. **过滤与清洗**：只保留**至少包含两种 SAE 类型共存**的页面（多 SAE 耦合原则）；单表格跨页时仍保留页面对；编译失败的 LaTeX 文件被丢弃；
4. **SAE 定位与标注**：结合正则匹配与 Mineru 解析结果，提取与视觉元素精确对齐的 LaTeX 源码作为标注；
5. **图表重建与专家验证**：图表先裁剪为 PNG，输入 Chart2Code 模型（Gemini-3-Pro）生成 Python 代码，渲染为 SVG 后由专家人工核对视觉信息、数据趋势与布局，通过后才作为标注（注意：这是"视觉推断的可执行表示"，而非原作者原始绘图代码）。

### 2.3 评估协议：再注入编译（Re-injection Compilation）
- 对每个生成的 Python 程序 $P_i$ 在隔离环境中执行，合成 SVG 文件 $G_i = \text{Execute}(P_i)$；
- 生成的 LaTeX 块 $L_p$ 必须显式引用这些生成资源（如 `\includegraphics{...}`）；
- 将 $L_p$ 结构性地再注入源上下文 $C_{\backslash p}$ 的切除点，由 LaTeX 编译器 $\Omega$ 渲染出预测页面 $\hat{I}_p$；
- 任何宏幻觉、嵌套环境未闭合或 Python 数据逻辑错误都会直接导致编译失败或严重视觉错位，构成严苛的保真度检验。

### 2.4 评估指标
| 指标 | 对象 | 说明 |
|---|---|---|
| Code Exec. Rate | 代码 | 再注入的 LaTeX/Python 能否编译渲染 |
| TEDS | 表格 | 结构与内容相似度 |
| PRS | 伪代码 | 文本保真度（归一化 Levenshtein）+ 结构保真度（树编辑距离），PRS = 50(R_text + R_struct) |
| Reading Order | 布局 | 阅读顺序错误率（越低越好） |
| PageIoU | 布局 | 页面级重叠度 |
| CDM | 公式 | 字符级匹配分数 |
| VRF-S | 表格/伪代码 | 严格变体：所有维度满分才算 100，否则 0 |
| VRF-A | 布局/图表 | 连续变体：各维度平均分 × 25 |
| Pixel Sim. | 全局 | 渲染页与真值页的像素相似度（含多页扩展处理） |

- 任何无法通过再注入编译的样本，相关指标直接记为 0。

## 3. 实验设计

### 3.1 基准数据集：CADP-Bench
- **规模**：1,630 个完整学术页面样本；
- **子领域分布**：计算机科学 1,047、物理学 251、经济学 45、定量生物学 222、统计学 65；

- **标注质量**：4 名精通 LaTeX/Python 的 CS 本科生共同标注，每样本双人独立审核，分歧由 CS 博士生裁决，整体一致性 88%。

### 3.2 评估的模型（SOTA MLLMs）
- **闭源前沿**：Gemini-3-Pro、Gemini-3-Flash、GPT-5.4、GPT-5.3-Codex、Claude Opus 4.6、Claude Sonnet 4.6、Claude Haiku 4.5、Kimi-K2.5；

- **探索性多智能体基线**：包含 Planner、LaTeX Coder、Python Coder、Reviewer 四个智能体，共享 OCR Parser、Color Picker、Code Executor、Snipping Tool、Notebook 等工具。

### 3.3 实验设置与任务（四个研究问题）
- 每个样本评估 3 次取平均；模型温度 0.7；所有 LaTeX 用 pdfLaTeX 编译；
- **RQ1（端到端性能）**：各模型在布局、公式、表格、图表、伪代码五类任务上的代码级与视觉级指标；
- **RQ2（复杂度与鲁棒性）**：按简单/中等/困难三档难度分析性能退化曲线；
- **RQ3（智能体技术影响）**：消融对比 Full MA System、w/o Visual Feedback、w/o Tools、w/o Multi-Agent、Base w/ Self-reflection 等配置；
- **RQ4（格式敏感理解）**：构造 90 个需跨 SAE 证据的人工问答，对比三种输入格式（整页截图、Markdown、结构化 LaTeX+Python）对模型回答准确率的影响。

## 6. 主要结论与发现

1. **前沿模型仍难高保真重建**：Gemini-3-Pro 综合最佳（如表格 VRF-S 63.09、图表 VRF-A 60.00、伪代码 VRF-S 56.52），但其布局 VRF-A 和 Pixel Sim. 仍不理想，说明完美重建仍是巨大挑战。
2. **开放权重模型快速追赶**：Qwen3.5-397B-A17B 整体视觉保真度已接近 GPT-5.4 和 Claude Opus 4.6，但伪代码等结构密集型元素在**所有**能力层级上都暴露严重弱点（GPT-5.4 伪代码 VRF-S 仅 13.04，Claude Opus 4.6 仅 17.39）。
3. **代码可执行性与视觉保真度系统性脱钩**：前沿模型图表代码执行率极高（约 94-98%），但 VRF-A 明显落后，说明"生成可运行的绘图代码"远比"忠实复现原图的细节美学与数据分布"容易。
4. **传统指标过于乐观**：TEDS 等指标高估表格解析质量，而严格的 VRF-S 揭示大幅性能滑坡——部分结构恢复不等于完美重建。
5. **难度敏感性与瓶颈**：公式和表格在中高能力模型上尚有一定鲁棒性，图表和伪代码在结构复杂度增加时成为主导瓶颈；弱模型（Qwen3.5-35B-A3B）在困难表格上接近地板水平。
6. **智能体技术的双刃剑效应**：完整多智能体系统带来约 3-7 点的稳定提升，但视觉反馈可能误导密集公式修正（反而降低分数）、多智能体传递可能破坏伪代码精确缩进、无外部环境支撑的自反思导致**全面性能回退**。
7. **结构保留表示有助于理解**：结构化的 LaTeX+Python 表示对中档模型（Qwen3.5-Plus）收益显著，甚至超越 Gemini-3-Pro 使用 Markdown 的效果；小模型则难以利用复杂程序化结构。

## 7. 优点与亮点

- **范式创新**：首次系统性地将学术文档解析重构为"像素到程序"的**双代码生成**任务，突破了 Markdown 的表示天花板，使结构、图表数据与渲染逻辑均可恢复、可执行、可验证。

## 8. 不足与局限性

- **真值构造依赖模型，存在偏差风险**：图表标注并非作者原始绘图代码，而是通过 Gemini-3-Pro 视觉推断生成的 Python 程序，经人工核验后作为真值。这意味着基准的"标准答案"本质上是对原图的一种近似重建，模型在评估中超越 Gemini-3-Pro 的余地有限，也可能继承其系统性偏差。
- **数据集规模与分布不均衡**：1,630 个样本总体规模中等，其中伪代码仅 138 个（约 8.5%），按难度细分后每档只有 27–71 个样本，统计功效有限；学科分布也高度偏向计算机科学（64.2%），经济学仅 45 页，跨领域泛化能力难以充分验证。
- **采样偏差**：数据全部来自 arXiv 且要求 LaTeX 源可用，无法代表无源 PDF、扫描文档、非 LaTeX 出版链（如 Word 转换稿）等真实世界的长尾场景；包声明 `C_{pkg}` 作为先验信息在实际应用中未必总是可得。
- **页面级粒度的局限**：基准虽保留了跨页表格对，但任务与评估总体上以单页为单位，未完全覆盖文档级的长程结构依赖（如跨页引用、章节间公式编号、全局宏定义等），这与真实论文的完整版式仍有距离。
- **评估成本与可复现性**：VRF 依赖 MLLM-as-a-judge，虽经一致性验证，但大模型判断的可重复性和调用成本仍是实际使用中的阻碍；多页像素相似度的计算方式也需更多消解细节。
- **算力与成本未披露**：论文未提供模型调用量、GPU 资源、标注工时成本等经济性数据，第三方复现时难以评估整体投入产出比。

## 9. 总体评价与启示

这是一篇典型的**数据—任务—评估三位一体的基准驱动型论文**：提出新任务（CADP 双代码生成）、构建新基准（CADP-Bench）、设计新评估协议（再注入编译），并将四个研究问题串成完整的实证故事。其核心贡献不在于提出更强的模型，而在于**重新定义了学术文档解析的"完成"标准**——不再以文本相似度或元素识别准确率论成败，而以"能否编译、能否渲染、能否忠实呈现结构细节"为终极检验，这为文档理解领域提供了更具工程意义的评价视角。

对后续研究的启示可归纳为五点：

1. **评价指标应从"文本相似"走向"可执行语义"**。TEDS 等传统指标在结构复杂的学术页面上会给出过于乐观的分数，严格变体（VRF-S）结合编译验证才是更具区分度的检验方式。
2. **结构化代码表示优于扁平标记语言**。LaTeX+Python 的双代码表示不仅恢复了表格与公式的结构，还使图表数据与渲染逻辑变得可审计、可复用，对下游知识抽取有实质增益。
3. **"代码可执行"与"视觉保真"是两种不同能力**。前沿模型图表代码执行率高达 94%–98%，但视觉保真度普遍落后 20–30 分，提醒我们在评估中必须区分"程序能跑"和"图长得像"这两个层次。
4. **智能体技术不是免费的午餐**。视觉反馈在布局修改上有效、在公式细修上可能误导；多智能体协作能提升整体稳定性，却会破坏伪代码的精确缩进；无外部工具支撑的自反思则全面回退。这表明智能体编排策略需要针对任务类型精细调优，而非简单堆叠。
5. **结构保留表示能显著降低下游模型的理解门槛**。对中等规模模型，结构化 LaTeX+Python 输入带来的收益可以抵消与顶级模型的代差，这为文档问答、知识图谱构建等下游应用提供了实用指导。

总体而言，论文以严谨的实验设计和高质量的基准建设，将学术文档解析推向"可编译、可渲染、可验证"的新阶段。其不足之处——图表真值的模型依赖性、样本量分布不均、页面级粒度限制——也为后续工作留下了明确的改进空间。对于关注文档逆向工程、科学知识抽取与多模态智能体的研究者，这是一篇具有参考价值的近期工作。该工作还提示了一个更宏观的方向：在 AI for Science 的时代，"结构化中间表示"或许是连接人类论文、机器理解与可复现科学成果的关键枢纽，而 CADP 是这一方向上值得跟踪的第一块里程碑。
