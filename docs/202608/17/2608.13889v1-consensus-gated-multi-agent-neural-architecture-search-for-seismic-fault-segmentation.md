## 摘要
用于地震断层分割的神经网络通常借用自计算机视觉和医学影像领域，这些领域在相对更大的标注数据资源下进行训练。在地球物理应用中常见的紧凑标注数据预算下优化其架构并非易事。手动设计数据最优架构耗时，而经典神经架构搜索（NAS）局限于手工设计的搜索空间和庞大的计算预算。我们提出了一种智能体式NAS系统，其中由三个大型语言模型（Claude、GPT-5.1和Gemini~2.5~Pro）组成的小组对每个候选架构进行辩论直至达成一致共识，编写完整的PyTorch实现，交叉审查，并将其提交至自动化的验证-训练-评分循环，具有450K参数的硬性预算、保留或回滚的血统以及失败机制的记忆。该系统直接在源代码上运行，而非预定义操作菜单，搜索在单个消费级GPU上进行，仅训练了八个候选模型。它发现了\ours{}：一个425K参数的编码器-解码器，具有条带池化瓶颈、挤压-激励门控、非对称单卷积解码器和特征金字塔融合颈部。在与所有基线相同的协议下，在源自Thebe断层数据集的剖面上训练，它在所有测试模型中取得了最高的F1（0.578）和IoU，同时体积最小，优于已发表容量的U-Net（31M参数，F1 0.484）、DeepLabV3-ResNet50（39.6M，0.516）和Attention U-Net（1.83M，0.502）。搜索成本为101次LLM调用（约1.15M输入/0.39M输出token）和大约一个GPU日，使共识门控的LLM小组成为领域特定架构发现的实用、低成本途径。

## Abstract
Neural networks for seismic fault segmentation are often borrowed from computer vision and medical imaging domains where they train under relatively much larger labeled data resources. Optimizing their architecture under tight labeled data budgets as are common in geophysical applications is not a trivial problem. Manually designing data-optimal architectures is time-consuming while classical neural architecture search (NAS) is restricted to hand-crafted search spaces and large compute budgets. We present an agentic NAS system in which a panel of three large language models (Claude, GPT-5.1, and Gemini~2.5~Pro) debates each candidate architecture to unanimous consensus, authors the complete PyTorch implementation, cross-reviews it, and submits it to an automated validate-train-score loop with a hard 450K parameter budget, keep-or-revert lineage, and a memory of failed mechanisms. Operating on source code rather than a predefined operation menu, the search ran on a single consumer GPU and trained only eight candidates. It discovered \ours{}: a 425K-parameter encoder-decoder with a strip-pooling bottleneck, squeeze-and-excitation gating, an asymmetric one-conv decoder, and a feature-pyramid fusion neck. Trained under a protocol identical to all baselines on sections derived from the Thebe fault dataset, it attains the highest F1 (0.578) and IoU of all models tested while being the smallest, outperforming a published-capacity U-Net (31M parameters, F1 0.484), DeepLabV3-ResNet50 (39.6M, 0.516), an Attention U-Net(1.83M, 0.502). The search cost 101 LLM calls ($\sim$1.15M input / 0.39M output tokens) and roughly one GPU-day, making consensus-gated LLM panels a practical, low-cost route to domain-specific architecture discovery.

### 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

**核心思想**  
将 LLM 作为“搜索算子”，直接编辑 PyTorch 源代码而非在预定操作菜单中挑选；并用“多模型辩论达到一致共识”作为质量门，仅把通过激烈审查的设计投入昂贵的训练验证。

**搜索循环（Search Loop）**
- 维护单一“血统（lineage）”：
  - run 0 训练一个 1.49M 参数的参考基线（预算豁免）。
  - 每轮 run 要求辩论面板基于当前父模型产生**一个架构变异**。
- **预训练验证器**（零 GPU 开销）：
  - AST 解析并实例化代码；
  - 在 batch=1 的三种剖面形状（256×256, 400×800, 600×1504）上完成前向/反向；
  - 保持空间维度不变；
  - 参数数 ≤ 450K。
- **保留/回滚机制**：
  - 候选从头训练后，使用**三次独立试验的平均 F1**（而非最好 F1）与父模型比较；
  - 若均值更高则保留，否则回滚，并将该机制加入**硬性禁用清单**，后续不可再引入。
- **停止准则**：
  - 硬性预算：最多 15 轮变异；
  - 停滞规则：最近三轮均超过基线均值，但运行最佳平均 F1 提升 <0.01，则停止。本次搜索在第 9 轮停止。

**辩论面板（Debate Panel）**
- 三个不同厂商的前沿模型：Claude、GPT-5.1、Gemini 2.5 Pro。
- PROPOSE 阶段：每个模型独立输出结构化规格：设计名、ADD/REMOVE/CHANGE 增量、拓扑、关键机制、预期参数数、与失败机制的区别、风险。
- DEBATE 阶段（最多 4 轮）：相互点名批评、可采纳对手设计，投 ENDORSE（选哪个规格）和 APPROVE（是否同意）两票；要求三人全部赞成同一规格才为共识。
- 若死锁，将分歧汇总后重新提案（最多 6 次重启）；仍无共识则该轮零 GPU 成本放弃。
- 共识达成后，胜出模型编写完整实现，另外两个模型按训练契约（接口、空间契约、batch-1 风险、超时风险）进行交叉审查，可修订最多两轮。

**训练协议与损失**（搜索与最终评估共用）
- 优化器：Adam，lr=1e-3，batch size=1；
- 损失：`L = CE_w(ŷ, y) + MSE(ẋ, x)`，即类加权交叉熵（断层权重15）+ 辅助图像重建项；所有网络都带分割头和一个单通道重建头；
- 无早停、无调度、无数据增强；
- 使用 GroupNorm（非 BatchNorm）以适应 batch=1；
- 搜索阶段：在训练集的 5 个固定等间隔剖面上训练，3 次试验×5 次重启×300 epochs，每次重启重新初始化；试验得分为 5 次重启中的最优 F1，保留/回滚使用 3 次试验的均值；
- 最终评估：全部 100 个训练剖面训练 60 epochs，全测试集评估，阈值 0.5 计算像素 F1。

### 6. 总结与核心贡献

本文的核心贡献在于提出了一种**低成本的“智能体式”神经架构搜索**（agentic NAS）范式，将大语言模型作为架构搜索的“运算符”。与传统NAS不同，该方法不再依赖人工定义的操作候选集或控制器网络，而是让三个商用前沿LLM通过辩论、投票和交叉审查的方式，直接修改PyTorch源代码。整个过程在极低的算力开销下（约1个GPU天+几百次API调用）完成了对真实地震断层分割网络的结构优化，最终得到的StripPool-UNet+FPN（0.43M参数）在F1上显著超过参数多40–90倍的U-Net、DeepLabV3等基线，且无需任何花哨的训练技巧。

这项工作的意义还在于：

- **首次将多LLM辩论引入物理地球科学领域的高效模型设计**，证明了“由AI自主构建专用网络”在数据稀缺、算力受限的实际场景中的可行性；
- 通过保留、回滚与“禁用清单”机制，将搜索过程变成一种**可解释的机制级消融**，从而揭示哪些高级模块（如深度可分离卷积、坐标注意力、非局部块）在断层分割任务中无效，为后续手工设计提供了负面证据；
- 提供了一套完整的、可复用的“LLM协作训练协议”：从结构化提案、约束条件、训练契约到多轮交叉审查，为其他学科使用LLM进行科研自动化提供了模板。

### 7. 局限性与未来工作展望

尽管本文表现出色，但仍存在明确的可改进方向：

- **搜索空间与候选多样性不足**：仅8个经过训练的候选和9轮搜索，较之传统NAS（成百上千个子网络）搜索覆盖有限，最终结构可能只是局部最优；
- **单数据集单任务验证**：断层分割仅是地震解释的一环，未检验该方法在其他地球物理任务（如盐体识别、层位追踪）或地质区块的通用性；
- **依赖闭源LLM与商业API**：辩论效果高度依赖于模型能力与版本，如果模型被更新，搜索行为会变化；未来的工作可探索开源模型（如Llama-3系列、Qwen2.5）作为替代，以提升可复现性与数据隐私；
- **训练协议的简化**：搜索阶段与最终评估使用相同的损失与优化器，未尝试FP16混合精度或更长的训练，可能导致搜索期性能低估了某些架构的真实潜力；
- **评估指标未覆盖断层几何特性**：可以引入细化后的F1-score（skeleton F1）、边界距离误差或形态学连续性指标，更贴近实际解释工作流；
- **未来方向**：将agentic搜索延伸到包括数据增强、损失函数、训练超参在内的联合搜索；使用RAG检索已发表的断层分割文献辅助LLM提出更合理的初始结构；在更大规模GPU集群上扩展“多血统”并行搜索，以加快搜索并减少因单点故障导致的资源浪费。

### 8. 总体评价

本文是一篇极具启发性的工作，它将“多智能体辩论”与神经架构搜索无缝结合，展示了LLM作为思考和创造工具在极小数据、极小算力环境下设计专业视觉网络的潜力。实验虽然规模不大，但设计严谨，尤其是“3次试验平均F1”作为保留/回滚准则、预训练验证器零成本淘汰非法代码、以及硬性禁用清单的做法，都体现了工程上对有限资源的精打细算。该论文为计算机视觉、地球科学交叉领域提供了一个低成本自动化模型设计的新范式，也为“AI for Science”增加了新的案例。

当然，由于依赖单一数据集和少量API调用，该结论的普适性和稳定性有待进一步检验。不过，考虑到当前NAS领域动辄需要上万GPU时计算量的现状，本文展现的工作效率与实用精神是难能可贵的。强烈建议对地震解释和低资源自动模型设计感兴趣的研究者阅读原文，并关注其后续在更大搜索规模、更广任务上的延伸版本。
