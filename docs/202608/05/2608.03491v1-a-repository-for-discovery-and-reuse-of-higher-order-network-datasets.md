## 摘要
高阶网络数据集分散在出版物、机构档案和特定软件集合中，使得它们难以被发现、比较和重用。我们介绍了亚琛高阶网络存储库（AHORN），这是一个从公开来源衍生的标准化高阶网络数据集的精选存储库。每个数据集条目都将转换后的数据集与其来源、元数据、引用指南、转换代码和版本历史相关联。该存储库支持可浏览和机器可读的发现、特定修订版的下载、格式验证以及用于互操作重用的导出。我们描述了存储库架构、策展工作流程、访问工具，以及本文分析中目录快照的覆盖范围和局限性。

## Abstract
Higher-order network datasets are dispersed across publications, institutional archives, and software-specific collections, making them difficult to discover, compare, and reuse. We introduce the Aachen Higher-Order Repository of Networks (AHORN), a curated repository of standardized higher-order network datasets derived from publicly released sources. Each dataset entry links a converted dataset to its source, metadata, citation guidance, conversion code, and version history. The repository supports browsable and machine-readable discovery, revision-specific downloads, format validation, and exports for interoperable reuse. We describe the repository architecture, curation workflow, access tools, and the coverage and limitations of the catalog snapshot analyzed in this article.

## 2. 提出的方法论

- **核心思想**：构建一个独立于特定软件栈的策展式数据存储库。将分散的公开数据源统一转换为标准化的高阶网络格式，记录元数据、来源、引用指南、转换代码和版本历史，提供人工可浏览与机器可读的双重访问路线。
- **关键架构细节**：
  - **数据模型**：采用行式纯文本交换格式（当前版本 0.3，支持 gzip）。首行为 JSON 元数据；后续行定义节点或交互（逗号分隔的节点标识列表），可附带 JSON 属性；多网络文件用 JSON 标记行分隔；支持权重、ISO 8601 时间戳等标准化属性。
  - **转换流程**：每个数据集由源特定的转换脚本处理，脚本随仓库提交并公开，确保可复现性。例如，图数据被提升为构建高阶表示（如团复形），MANTRA 数据记录流形级网络元数据，药物-靶标数据将交互和相似度矩阵转换为带秩标签的单元。
  - **策展工作流**：贡献者提交转换器、数据集页面和数据文件；维护者审核元数据完整性、转换可复现性、来源清晰性、验证成功与否及与仓库规范的兼容性。通过审核的数据集以版本化工件形式发布，保留旧版本以支持稳定引用。
  - **访问机制**：双路线——人类用户通过可浏览网页（含搜索/过滤）；机器用户通过 https://ahorn.rwth-aachen.de/api/datasets.json 获取机器可读索引；版本化数据归档于 Zenodo，提供稳定 DOI。
  - **互操作性**：除原生 AHORN 格式外，还为符合 HIF 模式的扩展集发布 HIF（Hypergraph Interchange Format）导出，支持 XGI、HyperNetX、SimpleHypergraphs.jl 等 HIF 兼容工具。
  - **配套工具**：`ahorn-loader` 同时提供 Python 库和命令行接口，支持检索（可固定版本）、缓存、直接流式读取数据集和提交前格式验证；格式规范公开维护。
- **引用策略**：引用 AHORN 平台引用本文；引用具体数据集则引用原始来源文献，可同时引用对应的 Zenodo 记录以标识确切版本。

## 6. 主要结论与发现

- AHORN 填补了高阶网络数据领域基础设施的空白，提供了一个**标准化、可引用存储、版本管理、可程序化访问**的独立数据仓库。
- 目录快照表明：AHORN 已能覆盖从紧凑教学型基准（如 MANTRA）到大规模实证数据集（百万级节点/交互）的广泛谱系，兼具静态与时序、单一与多种结构化类型的多样性。
- 通过公开转换代码 + 链接上游来源 + 版本化发布，数据集的可复现性和跨软件比较能力得到保障；HIF 导出和 TopoNetX 集成提供了跨生态互操作的路径。
- 元数据对于核心发现字段（领域、类型、规模等）覆盖率高，但外部引用和许可信息的覆盖不平衡，揭示出上游文档质量对数据基础设施的直接影响。

## 7. 优点

- **基础设施的独立性**：不同于 XGI-DATA 或 hypergraphx-data 这类绑定特定软件库的数据集包，AHORN 是独立的存储库，格式开放、不绑定任何单一工具链。
- **可复现性优先**：每个数据集都配备可公开访问的转换代码，来源可查、转换可复现；通过 Zenodo 提供修订级别的版本固定，支持基准工作的稳定复现。
- **FAIR 支持全面**：支持人工网页浏览、机器可读 JSON 索引、格式验证、版本化下载、格式规范公开，能够满足标准数据引用实践。
- **互操作双路径**：既提供原始友好格式（低摩擦、可读），又提供 HIF 导出以兼容 XGI、HyperNetX、SimpleHypergraphs.jl 等主流工具。
- **工程细节完整**：提供自动测试、数据验证器、预提交验证、CLI 和 Python 库双形态、本地缓存下载。
- **开放合规**：平台代码采用 AGPL v3.0，`ahorn-loader` 采用 MIT 许可，在 PyPI 分发。
- **伦理与合规敏感**：明确说明不收集新数据、须尊重原始许可证、包含使用条件与来源重新分发限制，并强调数据集的伦理责任仍归原始数据创建者。

## 8. 不足与局限

- **领域覆盖有偏**：目录的组成受限于公开可获得的来源、转换器编写工作量、上游元数据质量和再分发许可，导致领域分布不均匀。
- **元数据不完整**：引用与许可信息的覆盖不平整，部分数据集的溯源信息与使用权限说明有限。
- **格式支持有限**：当前交换格式还不支持有向交互和轨迹数据，这限制了某些类型系统（如方向性时间演化网络）的收录。
- **统计偏差风险**：目录级统计将父数据集与其派生子数据集视为独立观测，因此描述的是已发布条目清单而非相互独立的来源数据集。
- **合法授权边界**：数据集页面只记录上游使用条件，并未授予超出原始条件的权利，最终法律与伦理评估责任仍在下游用户。
- **缺少使用体验实证**：虽然已集成到 TopoNetX，但缺乏针对该仓库在真实研究任务中提升效率或可复现性的系统实证评估。
- **纵向深度不足**：尚无用户提交、审核周期、版本更新的具体运营数据，也未评估长期维护与社区参与模式的实际效果。
