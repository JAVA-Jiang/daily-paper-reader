## 摘要
本文研究了批处理大语言模型（LLM）服务中的资源分配低效问题：共享解码批次的异构请求相互之间施加了由最大值驱动的计算成本。由于批处理步骤的墙钟时间很大程度上由最大的活动KV缓存占用决定，短请求与长请求同批次处理时，其经历的延迟和GPU资源消耗可能与其自身的令牌工作量不成比例。我们将这一现象形式化为资源公平调度问题。我们开发了一个数学调度模型，将批内资源公平性与系统吞吐量联系起来。所提出的公平性约束限制了同批次请求之间解码进度（等效于KV缓存占用）的差异。基于该模型，我们设计了“限制插入短作业”（ISJL）算法，一种参数化的混合批处理策略。我们证明了ISJL实现了全局竞争比下界3/4。我们进一步研究了在商业LLM API使用的令牌计量定价惯例下，资源公平调度的利润影响。数值实验表明，ISJL在FCFS（批处理外部性大）和LJF（成本对齐但牺牲批处理灵活性）之间占据了一个有利的中间地带。因此，ISJL提供了一种双准则调度策略：在保持高吞吐量的同时，将最大值驱动的批处理成本与令牌计量收入对齐。

## Abstract
This paper studies a resource-allocation inefficiency in batched large language model (LLM) serving: heterogeneous requests that share a decode batch impose max-driven computational costs on one another. Because the wall-clock cost of a batch step is largely governed by the largest active KV-cache footprint, a short request co-batched with a long request can experience latency and GPU-resource consumption disproportionate to its own token workload. We formalize this phenomenon as a resource-fair scheduling problem. We develop a mathematical scheduling model that connects within-batch resource fairness to system throughput. The proposed fairness constraint bounds the disparity in decode progress, equivalently KV-cache footprint, among co-batched requests. Based on this model, we design the Insert-Short-Jobs-with-Limit (ISJL) algorithm, a parameterized hybrid batching policy. We prove that ISJL achieves a global competitive-ratio lower bound of $3/4$. We further examine the profit implications of resource-fair scheduling under the token-metered pricing convention used by commercial LLM APIs. Numerical experiments show that ISJL occupies a favorable middle ground between FCFS, which has large batching externalities, and LJF, which is cost-aligned but sacrifices batching flexibility. Thus, ISJL provides a bi-criterion scheduling policy: it maintains high throughput while aligning max-driven batch cost with token-metered revenue.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：在批处理LLM推理服务中，异构请求（长短不一的请求）共享同一解码批次时，批处理步骤的墙钟时间由批次中最大的活动KV-cache足迹决定，而非所有请求的平均值。这种"最大值驱动"（max-driven）的计算成本结构导致短请求被长请求"拖累"，经历了与其自身token工作量不成比例的延迟和GPU资源消耗。
- **研究背景**：LLM推理是服务运营商的主要持续性成本，现代系统（如Orca、vLLM）通过连续批处理（continuous batching）提高利用率，但批处理引入了外部性——短作业通过共享计算和KV内存实质上补贴了长作业。
- **研究定位**：作者提出一种"资源消耗公平性"（resource-consumption fairness）概念——不同于传统的伦理公平（如群体公平或结果均等），而是直接根据批内请求的KV-cache足迹（即解码进度）来定义公平。要求同一批次中共同调度的请求具有可比的解码进度，从而限制小足迹请求被大足迹请求主导的情况。
- **实际含义**：该工作不仅是一个调度理论问题，还连接了商业LLM API的令牌计量定价（token-metered pricing）惯例。在令牌单价固定的情况下，收入与调度策略无关，利润差异完全来自推理成本。资源公平调度因此成为将批量成本与令牌收入对齐的运营机制。

## 2. 方法论

### 2.1 核心建模思想

- **模型设置**：单计算节点、n个异构请求，每个请求i需要顺序生成 oᵢ 个token；最大批大小B；采用"令牌步骤"抽象（每个服务步骤每个活动请求前进一个token）。
- **公平性约束**：在任何时刻t，同一批次S(t)内请求的解码进度差异必须满足：
  - max_{i∈S(t)} aᵢ(t) − min_{i∈S(t)} aᵢ(t) ≤ α
  - 其中aᵢ(t)是请求i已生成的解码token数（即KV-cache足迹），α为可调公平性预算。
- **性能目标**：最大化吞吐量（=总token数 / makespan），该问题被证明在无公平约束时是强NP-hard的，因此需要近似算法。

### 2.2 算法设计

论文设计了两个主要算法：

**(1) Longest-Job-First (LJF)——静态批处理基准**

- 将请求按长度降序排序，把最长的B个请求组成一个批次运行，直到整批全部完成后再选下一批。批内所有请求同时启动、同步推进，因此天然满足任意α的公平约束（批内进度差异恒为0）。
- **竞争比理论保证**：CR(LJF) ≥ B/(2B−1)，当B=2时最大值为2/3，随B增大而单调递减。

**(2) Insert-Short-Jobs-with-Limit (ISJL)——参数化混合批处理策略**

- **核心思想**：在静态批处理与连续批处理之间取折中。阶段一（Phase ONE）围绕最长请求构建结构化的短作业包，控制初始KV-cache差异不超过α；阶段二（Phase TWO）采用事件驱动的连续批处理，只要有资源释放且当前最大进度≤α，就立即接纳下一个最长未处理请求。
- **关键参数**：β = (√17−1)/4 · α ≈ 0.78α 为最优参数，使B=2时竞争比下界达到(25+√17)/38 ≈ 0.77；简化选择β=α时竞争比为3/4。
- **一般化（B≥2）**：证明CR(ISJL) ≥ 3/4（固定β=α）。
- **鲁棒扩展（Robust-ISJL）**：当输出长度未知时，使用预测区间上限 uᵢ 作为代理长度进行调度，运行时的公平性检查使用真实进度。证明在任何预测误差下Robust-ISJL都满足公平约束，并给出依赖预测误差的竞争比退化保证。
- **在线扩展**：Online-ISJL以滚动方式实现，证明公平性始终可满足，但竞争比3/4无法在对抗性到达时间下保持。

### 2.3 竞争比与公平预算的关系

论文进一步推导了归一化公平参数 γ = α/o₁ 与竞争比下界的精确分段函数关系（Theorem 6）：

- CR(γ) = (1+γ)/(1+2γ)，当 0 < γ ≤ 1/2
- CR(γ) = (2−γ)/(3−2γ)，当 1/2 ≤ γ < 1
- 在γ=1/2处取得唯一全局最小值3/4，在γ→0或γ→1时趋于1

**核心含义**：α太小限制批处理灵活性，α太大增加批处理外部性，最优折中在γ=1/2处；当α接近0（严格同质）或接近最长作业长度（几乎无约束）时，效率可达最优。

### 2.4 利润与成本分解

论文建立了批步骤成本模型：C_A(t) = c + τ|S(t)|·max_{i∈S(t)} rᵢ(t)，即固定每步开销 + 批内最大KV足迹驱动的成本。

**核心定理（Theorem 7）**——利润分解：

$$Π_A(I) = R(I) − τQ(I) − cT_A(I) − τE_A(I)$$

- R(I)：令牌计量收入（调度无关）
- τQ(I)：内在工作量成本（调度无关）
- cT_A(I)：时间/开销成本（由makespan决定）
- τE_A(I)：调度引起的批处理外部性成本（由批内进度错位决定）

**关键保证**：任何α-公平调度满足 E_A(I) ≤ αO(I)，即外部性成本被公平预算α直接约束。

**利润保证（Theorem 8）**：ISJL相对于最优α-公平利润调度只有两个利润损失通道——由makespan次优性导致的c(1/ρ−1)T_π⋆(I)项，以及由外部性导致的ταO(I)项。

## 6. 主要结论与发现

1. **理论发现**：ISJL算法在任意α和B≥2下实现3/4的全局竞争比下界；竞争比随γ = α/o₁ 呈U形，在γ=1/2处最坏，在γ→0或γ→1时趋于最优。

2. **利润实验方面**：LJF利润最高（163.82）、外部性为0；FCFS因巨大的批处理外部性（35.10）利润最低（128.73）；ISJL在两者之间绘制管理前沿——α=50时利润接近LJF（差0.8%）但吞吐提升3.5%；α=300时吞吐提升20.31%而利润仅比LJF低5.56%。当固定每步开销c超过0.0162时，ISJL(α=50)的利润将超过LJF。

3. **效率实验方面**：ISJL在两种批大小下同时实现了比所有基准更高的吞吐量和更低的AEL。B=16时，ISJL(α=150)吞吐量276（比LJF高14%、比SJF高28%）；ISJL(α=50)的AEL为53（比LJF低20%）。α参数提供可调的效率-延迟权衡：小α优化AEL，大α优化吞吐量。

4. **核心调和性发现**：纯吞吐量标准在经济上可能误导——FCFS可能比LJF更快完成，但产生二次级的批处理外部性；ISJL是双准则策略，在保持高吞吐的同时控制成本错位。

## 7. 优点与亮点

- **理论贡献扎实**：提供了LLM调度领域少见的严格竞争比分析（3/4下界、参数化界、鲁棒扩展），将公平性约束与吞吐量目标在统一的优化框架下建模。
- **问题定义精准**：正确捕捉了LLM推理的独特特征（KV cache异构性、最大值驱动的批步成本、连续批处理的外部性），并给出形式化定义。
- **竞争比上界精确刻画**：Theorem 6的分段函数结果优雅地刻画了公平预算α与效率的关系，对实际操作有指导意义。
- **经济分析框架创新**：将调度策略与令牌计费定价环境结合，给出利润分解定理（Theorem 7），区分了内在工作量成本、时间成本和外部性成本——为运营商提供了清晰的成本归因视角。
- **鲁棒性设计**：Robust-ISJL在预测不确定下仍保证公平性约束，且竞争比退化程度与预测误差呈优雅的函数关系，实用性强。
- **诚实的方法论**：明确讨论模型的适用范围（离线积压快照假设、计算受限而非内存受限、在线竞争比下界极限），不夸大结论。
- **双准则视角**：不以单一方针（纯吞吐或纯成本）评判调度策略，而是以成本和效率双维度刻画ISJL的帕累托前沿位置。
