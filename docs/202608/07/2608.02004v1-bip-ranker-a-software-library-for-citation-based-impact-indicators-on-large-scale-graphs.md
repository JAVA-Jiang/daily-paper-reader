## 摘要
科学影响力是多维的：总体影响力、当前热度、早期引文动量以及领域相对表现各自捕捉了出版物影响力的不同方面。然而，在实践中，这些维度往往被简化为单一指标，例如引文数量。能够大规模计算多种互补影响力指标的开源解决方案仍然稀缺，尤其是对于像主要学术数据库提供的那么大的引文图。我们介绍了BIP! Ranker，一个基于Spark的开源软件库，用于大规模计算基于引文的科学影响力指标，能够处理包含数亿出版物之间数十亿条引文的引文网络。

## Abstract
Scientific impact is multidimensional: overall influence, current popularity, early citation momentum, and field-relative performance each capture a distinct facet of a publication's impact. Yet, in practice, these dimensions are often reduced to a single metric, such as citation count. Open solutions for computing multiple complementary impact indicators at scale remain scarce, particularly for citation graphs as large as those provided by major scholarly databases. We introduce BIP! Ranker, an open-source, Spark-based library for computing citation-based impact indicators at scale, capable of processing citation networks with billions of citations among hundreds of millions of publications.

## 2. 论文提出的方法论

- **总体架构**：BIP! Ranker 以 Apache Spark（PySpark）作为分布式计算引擎，包含两个核心组件：
  - **Citation Network Analysis（引文网络分析）**：直接在引文网络上计算各影响力指标，输出出版物的指标得分和基于百分位的等级类别。
  - **Field Normalisation（领域归一化）**：结合出版物-领域映射，计算领域归一化指标（FWCI 及 N 年 FWCI）和领域内百分位等级。
- **输入输出**：输入为引文网络（HDFS 上的分布式存储）和出版物-领域映射；输出为指标分数、百分位类别、领域相关指标等。
- **实现的指标家族与公式**：
  - **影响力（Influence）**：
    - **Citation Count (CC)**：直接统计引文入度，`CC_i = Σ_j A_ij`，其中 A 为引文图的邻接矩阵。
    - **PageRank**：基于随机游走模型传播分数，`PR_i = α Σ_j P_ij PR_j + (1-α)/|V|`，其中 P 为归一化转移矩阵，α 为阻尼因子。通过 checkpoint 中间 DataFrame 防止数据谱系膨胀，以支持大规模迭代。
  - **流行度（Popularity）**：
    - **RAM（Recency-Aware Momentum）**：对每条引文按引用年份进行时间衰减加权，`RAM_i = Σ_j R_ij`，其中 `R_ij = γ^(tc - tj)`，γ 为衰减因子，tc 为当前年，tj 为引用论文发表年。
    - **ECM（Extended Citation Momentum）**：在 RAM 基础上沿整个引用链传播衰减加权分数，`ECM_i = Σ_j Σ_h λ^h (R^h)_ij`，λ 为链长衰减参数，H 为最大链长；RAM 是 ECM 的单跳特例，共享同一计算管线。
    - **AttRank**：扩展 PageRank，将跳转（teleportation）分量改为结合发表与引用时近性的注意力信号，`AttRank_i = α Σ_j P_ij AttRank_j + β·Att(i) + γ·c·e^(-ρ(tc - ti))`，其中 α + β + γ = 1。
  - **脉冲（Impulse）**：
    - **iCC（Incubation Citation Count）**：只统计发表后 N 年窗口内收到的引文的变体 CC，`iCC_i^(N) = Σ_(j: tj ≤ ti + N) A_ij`，用于捕捉早期引文动量。
  - **领域归一化（Field-normalised）**：
    - **FWCI**：`FWCI_i = CC_i / E[CC | d_i, y_i, f_i]`，即引用数除以同类型、同年份、同领域的期望引用数。
    - **N-year FWCI**：将上式中的 CC 替换为 iCC^(N)，并对观察值和期望值都做同样的时间窗口限制。
- **输出类别**：所有指标均按分数降序将出版物划分为 Top 0.01%、Top 0.1%、Top 1%、Top 10% 和 Average 五类，并支持在领域内单独划分，以实现领域相对的评估。
